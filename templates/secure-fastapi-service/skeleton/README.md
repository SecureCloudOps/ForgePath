# __FORGEPATH_SERVICE_NAME__

__FORGEPATH_SERVICE_DESCRIPTION__

Generated by ForgePath's `secure-fastapi-service` paved path. The service has
live and ready health checks, Prometheus metrics, structured JSON request logs,
request IDs, and graceful ASGI lifespan shutdown.

## Local development

Use Python 3.12 and install the fully pinned runtime and development dependencies:

```sh
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt -r requirements-dev.txt
.venv/bin/ruff format --check .
.venv/bin/ruff check .
.venv/bin/mypy
.venv/bin/python -m pytest
```

Run the service:

```sh
.venv/bin/python -m uvicorn app.main:app --host=127.0.0.1 --port=8080 --no-access-log
```

Endpoints are `/health/live`, `/health/ready`, and `/metrics`. Supply
`X-Request-ID` to preserve an upstream correlation ID; otherwise one is created.

## Container

```sh
docker build --tag __FORGEPATH_SERVICE_NAME__:0.1.0 .
docker run --rm --read-only --tmpfs /tmp:rw,noexec,nosuid,size=16m \
  --user 10001:10001 -p 8080:8080 __FORGEPATH_SERVICE_NAME__:0.1.0
```

The base image is pinned by digest and the runtime user is UID/GID 10001.

The namespace boundary includes ResourceQuota and LimitRange. Its default
NetworkPolicy selects every pod and denies all ingress and egress. DNS is the
application's only egress exception and is restricted to kube-system DNS pods
on UDP/TCP 53. Prometheus access to `/metrics` requires both configured
namespace and pod selectors and TCP 8080. Enable
`networkPolicy.applicationIngress.enabled=true` only when a caller matching
both configured selectors should reach the application on port 8080.
